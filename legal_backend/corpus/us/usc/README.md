# US Code USLM cache

Place per-title OLRC USLM XML files here for offline ingest when `uscode.house.gov` is unreachable:

- `title-1.xml` through `title-54.xml` (skip title 53)

Download from: https://uscode.house.gov/download/download.shtml

Set `USLM_RELEASE_PATH=119/99` (or current release) for automatic fetch attempts.
