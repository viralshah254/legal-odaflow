# Accessibility And Localization Checklist

- Icon-only controls must have an accessible label.
- Forms need visible labels or screen-reader labels.
- Error, loading, empty, and success states should announce meaningful text.
- Avoid hard-coding jurisdiction-sensitive copy where country configuration exists.
- New user-facing strings should be easy to move into localization dictionaries.
- Check keyboard navigation for dashboards, tables, dialogs, and command surfaces.
