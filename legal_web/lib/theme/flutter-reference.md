# Flutter theme reference

Shared tokens live in [`../../shared/theme/tokens.json`](../../shared/theme/tokens.json).

| Web CSS var | Flutter |
|-------------|---------|
| `--primary` | `AppColors.primaryLight` / `primaryDark` |
| `--background` | `AppColors.backgroundLight` / `backgroundDark` |
| `--radius` | `BorderRadius.circular(12)` |
| Inter | `GoogleFonts.inter()` |

See `legal_app/lib/core/theme/app_colors.dart` for implementation.
