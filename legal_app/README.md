# Umbrella — Mobile

Flutter app for consumers and lawyers.

## Quick start

```bash
flutter pub get
cp config/dart_defines.local.example.json config/dart_defines.local.json
```

Then press **F5** (Run and Debug → **Umbrella (local API)**). No manual flags needed.

See [APP-STORE-RELEASE.md](https://github.com/viralshah254/legal-odaflow/blob/main/APP-STORE-RELEASE.md) for store signing and FCM setup.
